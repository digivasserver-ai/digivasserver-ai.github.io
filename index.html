About

I work on practical tools for AI-assisted development and Android: durable agent memory, clear security boundaries, reproducible builds, and small fixes backed by tests. I separate working prototypes from shipped features, and I mark what I have not verified.

My daily test environment is Android 16 on an aarch64 openSUSE Tumbleweed proot terminal with ADB and Shizuku — which exposes platform assumptions that desktop-only builds miss.
