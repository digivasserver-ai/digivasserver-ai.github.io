# digivasserver-ai.github.io

Source for <https://digivasserver-ai.github.io/> — a small static site with no build step.

- `index.html` — landing page: selected work, writing, contact
- `signal-36.html` — Android's `traced_perf` / `BIONIC_SIGNAL_PROFILER` deep dive
- `arm64.html` — building Android on an ARM64 phone (aapt2, compileSdk 37, Gradle traps)
- `style.css` — single stylesheet, dark palette

Plain HTML and CSS. No JavaScript, no dependencies, no CI. Edit and push; GitHub Pages serves `main` directly.
